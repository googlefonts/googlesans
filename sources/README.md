This directory exists because [crater][] does source discovery by looking for
a gftools [config.yaml] file in a directory named `sources` or `Sources`.

This repository has historically used a `source` directory instead, and so
as a stopgap we have added a `sources` directory here, so crater can find our
source files.

[crater]: https://googlefonts.github.io/fontc_crater/
[config.yaml]: https://github.com/googlefonts/googlefonts-project-template/blob/main/sources/config.yaml
